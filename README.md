Beacon Hunter

Beacon Hunter — это инструмент для Blue Team и SOC-аналитиков, предназначенный для обнаружения скрытых каналов управления (C2) в сетевом трафике. Он использует статистический анализ таймингов (Network Beaconing) для выявления периодической активности, характерной для вредоносного ПО.

Проблема
Современные C2-фреймворки (Cobalt Strike, Havoc, Sliver) часто используют шифрование (TLS), что делает невозможным обнаружение угроз по сигнатурам в теле пакета. Однако поведение малвари остается предсказуемым: бот должен периодически "опрашивать" сервер (heartbeat/beacon).

Основные возможности
Анализ периодичности: Вычисление коэффициента вариации интервалов (Jitter).
Детекция в зашифрованном трафике: Работает на уровне метаданных потоков (Flows), не требуя расшифровки TLS.
Интерактивные отчеты: Генерация графиков в формате HTML для визуального подтверждения аномалий.
Scoring System: Гибкая система оценки подозрительности каждого соединения от 0 до 100.

## Установка и использование

1. Клонируйте репозиторий:
   ```bash
   git clone [https://github.com/your-username/beacon-hunter.git](https://github.com/your-username/beacon-hunter.git)
   cd beacon-hunter
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите анализ PCAP-файла:
   ```bash
   python main.py data/sample_malware.pcap
   ```
